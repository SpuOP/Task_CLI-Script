# Task CLI Script

A simple Python command-line task manager built with argparse and JSON storage.

## Features
- Add tasks
- List tasks
- Mark tasks as complete
- Delete tasks

## Usage

Add a task:
```bash
python -m resolution_week1_spuop.main "Do homework"
python -m resolution_week1_spuop.main --list
python -m resolution_week1_spuop.main --complete 1
python -m resolution_week1_spuop.main --delete 1
